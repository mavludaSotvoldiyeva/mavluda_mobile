# Riverpod Ticker

Simple Flutter app for Lab 6.

Run:

```bash
flutter pub get
flutter run
flutter analyze
flutter test
```

Use the warning button to force an error after five updates, the check button to return to normal, and refresh to reconnect. You can also pull down on the ticker list to refresh.

If starting from this ZIP, create the platform folders with `flutter create .` before running.

Git commits and tags must be made in your own repository. The screen recording also needs to be made on your device.
